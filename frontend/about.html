How It Works

📦 Borrowing Gear

  1. Browse the gear page. Photos, descriptions, tags, and availability help you identify the exact items you need. Gear groups such as a Nuts group or Trad Rack can be added together.
  2. Open My Loans and start a loan.
  3. Choose T-wall for climbing at Trinity Wall, or Outdoor for taking gear away.
  4. For an outdoor loan, choose the start and end dates. You can book from today or for a future date.
  5. If you have automatic access, the loan starts immediately. Otherwise, your request is sent to Tom for approval.
  6. Take the gear you need from the locker. No verification code or combination code is required for borrowing.
  7. Use the Trinity Wall door code shown on your loan when access to the wall is required. This code is provided for both T-wall and Outdoor loans.
  8. In My Loans, search by tag or name and log every item you take.

↩️ Returning Gear

  1. Return every item to its correct locker, placed neatly and safely 🙏
  2. Open My Loans and find the active loan.
  3. Upload a photo for each locker used, showing that the gear has been returned.
  4. Click Confirm Return. The system records the return and updates availability.

❓ Need Help?

Locked out, item missing, or something not working? Contact Tom in person or text him on Whatsapp.
